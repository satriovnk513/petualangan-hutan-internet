# Ikon lencana

Saat ini lencana masih memakai emoji (lihat `badge.emoji` di `src/data/levels.js`).
Untuk mengganti dengan ilustrasi asli, simpan berkas di folder ini dengan nama:

- `penjaga-rahasia.png`
- `detektif-informasi.png`
- `pemburu-jejak-ai.png`
- `sahabat-digital.png`
- `penjaga-hutan-internet.png`

Lalu impor di `src/utils/assets.js` dan pakai di `src/components/BadgeCard.jsx`.
Ukuran yang disarankan: 512 x 512 piksel, PNG dengan latar transparan.
