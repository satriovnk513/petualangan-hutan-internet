# Materi unduhan

Folder ini disiapkan untuk panduan PDF yang bisa diunduh guru dan orang tua.

Saat ini folder sengaja kosong: tombol unduh di halaman "Panduan untuk Guru"
dan "Panduan untuk Orang Tua" ikut disembunyikan supaya berkas contoh tidak
pernah tampil seolah-olah panduan yang sudah jadi.

Setelah panduan asli siap, simpan di sini dengan nama:

- `teacher-guide.pdf`
- `parent-guide.pdf`

Lalu tampilkan kembali tombol unduhnya dengan menambahkan komponen
`DownloadCard` di `src/pages/Teachers.jsx` dan `src/pages/Parents.jsx`
(lihat catatan di bagian atas kedua berkas itu).
